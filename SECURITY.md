# Security Policy

## Supported Versions

| Version | Supported |
|---------|-----------|
| latest  | ✅        |

## Reporting a Vulnerability

If you discover a security vulnerability in this project, please report it **privately** to avoid public exposure before a fix is available.

**Contact:** [emonnet-mata@guardiaschool.fr](mailto:emonnet-mata@guardiaschool.fr)

Please include in your report:
- A description of the vulnerability
- Steps to reproduce
- Potential impact

We aim to acknowledge reports within **48 hours** and provide a fix or mitigation within **7 days** depending on severity.

Do **not** open a public GitHub issue for security vulnerabilities.
